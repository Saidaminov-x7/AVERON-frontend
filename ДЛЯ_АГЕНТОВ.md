# РУКОВОДСТВО ДЛЯ AI-АГЕНТОВ: ПУБЛИЧНЫЙ САЙТ (IJARAUZ NEXT.JS)

> **Назначение документа:** Справочник по архитектуре, правилам разработки, роутингу, стилизации и обработке данных для клиентского сайта **Ijarauz**.

---

## 1. СТЕК ТЕХНОЛОГИЙ И АРХИТЕКТУРА

- **Фреймворк:** Next.js 16 (App Router + Turbopack).
- **Библиотека компонентов:** React 19, Lucide React Icons.
- **Стилизация:** TailwindCSS + Vanilla CSS переменные (дизайн-токены).
- **Интернационализация:** `next-intl` (поддерживаемые языки: `ru`, `uz`, `en`).
- **Сетевой клиент:** Axios (кастомный инстанс с JWT-перехватчиком и `withCredentials`).
- **Карты и геоданные:** Leaflet / Yandex Maps / Custom Map Clusters.
- **Стейт-менеджмент:** Zustand (`useAuthStore`).

### 3.2. Локализация и Роутинг (`next-intl`)
- Всегда оборачивайте ссылки в локализованный `Link` или используйте `useRouter` / `usePathname` из `@/i18n/routing`.
- При редиректах (например, в `ProtectedRoute.tsx` или `GoogleAuthButton.tsx`) **обязательно сохранять текущую локаль** (`/${locale}/login?redirect=...`).

### 3.3. Стандарты верстки и UI
- **Высота инпутов и кнопок:** Единый стандарт высоты интерактивных элементов — `h-10` (40px).
- **Скругления:** Карточки — `rounded-2xl` или `rounded-3xl`, кнопки и инпуты — `rounded-xl`.
- **Чат:** Страница чата (`/chat`) использует `height: 100dvh`, футер на странице чата скрывается через `NO_FOOTER` в `AppChrome.tsx`.
- **Модальное окно жалоб:** Содержит опцию `REALTOR` («Это риелтор / Агентство») для оперативной отправки в антифрод-систему.

### 3.4. Обработка ошибок (Error Handling)
- Любые неперехваченные ошибки UI перехватываются через `GlobalErrorListener` и `global-error.tsx` и отправляются в фоновом режиме на эндпоинт бэкенда `POST /error-reports`.

## 4. СБОРКА И ПРОВЕРКА

Перед коммитом агент **ОБЯЗАН** выполнить сборку:
```bash
npm run build
```
Сборка запускает TypeScript typecheck, генерацию статических страниц и Turbopack бандлинг. Код возврата должен быть равен `0`.
