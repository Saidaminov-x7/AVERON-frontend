# AVERON storefront — заметки для разработчиков

Публичная витрина AVERON построена на Next.js App Router, React, TypeScript и
Tailwind CSS. Локализованные маршруты и переводы поддерживают `ru`, `uz` и
`en`; общие строки хранятся в `messages/`.

## Правила изменений

- Общие цвета, поверхности, состояния, радиусы, шкала типографики и анимации
  витрины задаются в `app/[locale]/globals.css`. Используйте CSS-переменные и
  семантические классы вместо новых локальных палитр; сохраняйте контраст
  светлой и графитовой тёмной темы.
- Для повторяющихся контролов используйте классы `averon-control-button`,
  `averon-primary-button`, `averon-secondary-button`, `averon-menu-surface` и
  `averon-menu-item`. Не задавайте для drawer, dropdown или popover отдельные
  фиксированные значения цветов темы.
- Общая геометрия и focus/disabled состояния кнопок, текстовых полей и меню
  нормализуются в `globals.css`. Не добавляйте к стандартным CTA переопределения
  радиуса (`rounded-none`) или локальные цвета; контрастные варианты поверх фото
  оформляйте через контекстные классы, сохраняя общие размеры и радиус.
- Считайте текущие маршруты и API-контракты источником истины. Не добавляйте
  маршруты или UX прежнего сервиса аренды.
- Каталог, цены, доступность, промокоды и оформление заказа должны опираться на
  данные и решения Backend. Не подменяйте отсутствующий ответ выдуманными данными.
- Не публикуйте приватное состояние в SEO: личный кабинет, корзина, оформление,
  заказы, избранное, сравнение, образы, авторизация и Mini App должны оставаться
  вне индекса и sitemap.
- Для перевода используйте общий словарь и проверяйте одинаковый набор ключей
  RU/UZ/EN. Не добавляйте обычный UI-текст через условные выражения по locale.
- Внешние/возвратные URL проверяйте существующими безопасными навигационными
  helpers. Не передавайте секреты и персональные данные в аналитику.
- Не включайте необязательные провайдеры только наличием UI или адаптера:
  сверяйте Backend capabilities и статус реальной конфигурации.

## Проверки

Из каталога `AVERON_frontend`:

```sh
pnpm test
pnpm lint
pnpm exec tsc --noEmit
pnpm build
```

См. `README.md` для команд запуска и актуального описания storefront.
