# AVERON UI audit

Date: 2026-10-07  
Scope: `AVERON_frontend` storefront and `AVERON_admin_panel` admin UI.  
Method: route/component/CSS source inspection against existing responsive layouts and the local Stitch reference package. This is a source audit; no page was changed as part of this phase. Browser screenshots, live viewport checks, and interactive regression runs belong to the implementation/review phase and remain pending.

## Impeccable baseline detector

The standalone detector was run once against the existing storefront and admin source. It reported `MaintenanceView.tsx` (`animate-bounce`; dark text on amber), admin `index.html` and `FullScreenLoader.tsx` (violet palette), admin `index.css` (Inter), and `UserProfilePage.tsx` (2px tab indicator). These are source-level heuristic flags, not proof of a rendered defect. The dark-on-amber flag is specifically a manual contrast check; all other findings are represented above. A final detector pass is still required after implementation, when changed UI files are stable.

## Existing strengths to preserve

- Storefront tokens already cover light/dark surfaces, typography, spacing, radii, motion, and breakpoints in `app/[locale]/globals.css`.
- `ProductCard` uses a consistent `3/4` product image, supports alternate images, and exposes favorite/compare actions.
- Product gallery, variant selection, size chart, catalog filters, and smart-back behavior already have dedicated components or tests.
- Storefront controls have visible keyboard focus and 44px minimum targets; modal and admin drawer code already account for Escape, focus, and scroll handling.
- Admin has a shared UI component set, localized message catalogs, and a distinct dense operational layout.

## Audit limits

This report records source-level findings, not a claim that every state was reproduced in a browser. Browser review should cover storefront RU/UZ/EN at 390px and 1440px, plus admin `/login`, `/products`, `/orders`, and product editor at the same widths. Hosted production checks must remain read-only and must not use production credentials or submit orders, payments, product publication, or destructive actions.
