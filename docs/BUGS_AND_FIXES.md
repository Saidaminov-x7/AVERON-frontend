# AVERON bugs and fixes

Date: 2026-10-10. Production observations were read-only. Code changes below are in the isolated `AVERON-clones/AVERON-frontend` checkout and have not been deployed.

Latest mobile drawer fix (2026-10-09): the original full-viewport panel was visually oversized and obscured the entire page. It is now a capped right-side drawer with compact rows/cards and fixed account/locale/theme actions; the central links scroll independently on short displays. Chrome DevTools checked light/dark phone and tablet dimensions, desktop breakpoint, Escape/focus restoration, and overflow. Changes are local only.

Automated regression (2026-10-09): added six stable `STORE-MOBILE-MENU-*` action IDs and local-only Playwright coverage. Six desktop/mobile Chromium scenarios passed after aligning the assertion with the actual guest behavior: Favorites redirects to login with a safe `returnTo`, not to an unauthenticated favorites page. Third-party HTTPS traffic is blocked during the test; production is not used.
